# Description
A 3D space orrery created in babylon for the Nasa Space Apps hackathon.

![screenshot](planetary_orbit1.gif)
![screenshot](planetary_orbit2.gif)
![screenshot](NasaTeamPicture.jpg)


# How to run
1. ```npm i```
2. ```npm start``` 
3. open on http://localhost:8080/
